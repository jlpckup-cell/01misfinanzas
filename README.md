# MisGastos

App de control de gastos mensual: nómina, gastos fijos por categoría y gastos del día a día. Funciona offline y es instalable en el móvil.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `misgastos`).
2. Sube todos estos archivos a la raíz del repositorio (no dentro de una subcarpeta).
3. Ve a **Settings → Pages**, en "Source" elige la rama `main` y la carpeta `/ (root)`. Guarda.
4. Espera 1-2 minutos y tu app estará en `https://tu-usuario.github.io/misgastos/`.

## Instalar en el móvil

- **Android (Chrome):** abre la URL, toca el menú (⋮) y elige "Añadir a pantalla de inicio" o "Instalar app".
- **iPhone (Safari):** abre la URL, toca el botón de compartir y elige "Añadir a pantalla de inicio".

Los datos se guardan solo en el propio dispositivo (localStorage), no hay servidor ni cuenta.
